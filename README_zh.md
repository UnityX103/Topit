# Topit：区域与整窗置顶

[English](README.md) · [下载版本](https://github.com/UnityX103/Topit/releases) · [自动测试](https://github.com/UnityX103/Topit/actions/workflows/ci.yml)

Topit 是 macOS 上的窗口置顶工具。这个仓库在 [lihaoyun6/Topit](https://github.com/lihaoyun6/Topit) 的基础上增加了**可交互的区域置顶**：框选窗口中的一小块内容，让它作为独立浮窗保留在屏幕上。原项目的整窗置顶及相关设置继续保留。

适合只保留聊天输入区、任务进度或其他局部内容的场景。当前发布处于预发行阶段，后台输入的兼容性取决于源应用；已知限制见下文。

## 两种模式及功能来源

| 能力 | 来源 | 使用入口 |
| --- | --- | --- |
| 整个窗口置顶、同时保留多个窗口 | 原项目已有 | 选择器的「立即置顶」；菜单栏「置顶某个窗口」 |
| 整窗暂停/恢复、不透明度、解除置顶、关闭原窗口 | 原项目已有 | 整窗浮层角落的 Topit 控制菜单 |
| 整窗激活方式、防止焦点切换、自动闪避、帧率设置 | 原项目已有 | 设置 → 窗口设置 |
| 按显示器浏览窗口、直接点选窗口、App 过滤、自定义快捷键、AppleScript | 原项目已有 | 窗口选择器、设置及脚本命令 |
| 框选局部内容并生成实时浮窗 | 本仓库新增 | 「区域置顶…」或 Command + Shift + T |
| 区域鼠标操作映射、原输入框焦点交接 | 本仓库新增 | 点击区域浮窗中的对应位置 |
| 区域移动/等比缩放、冻结/恢复、复制截图、透明度 | 本仓库新增 | 按住 Shift 编辑浮窗 |
| 双击 Control 开关区域自动隐藏 | 本仓库新增 | 双击 Control；「区域截取」菜单 |
| 固定签名增量更新、备份回退、GitHub 测试与发布校验 | 本仓库新增 | 更新脚本与 [发布文档](docs/RELEASING.md) |

**整窗置顶和区域置顶使用不同的交互方式。** 原项目的「自动闪避」「防止输入焦点改变」是整窗模式设置；新增的双击 Control 自动隐藏作用于区域浮窗。

## 安装与首次授权

- 使用 macOS 13 或更高版本；发布的通用应用包含 Apple Silicon 和 Intel 架构。
- 从[本仓库 Releases](https://github.com/UnityX103/Topit/releases)下载 `Topit-版本号-macOS-universal.zip`，解压并将 `Topit.app` 放入 `/Applications`。
- 当前发行使用固定本地证书签名，未经 Apple Developer ID 公证。首次安装或更换签名身份可能需要重新授权。
- 原作者的 Homebrew 配方安装的是上游版本，不包含这里新增的区域功能。

首次启动时，按应用内提示授予两项权限：

| 权限 | 用途 |
| --- | --- |
| 屏幕录制 | 捕获所选窗口的图像 |
| 辅助功能 | 选择窗口、控制窗口及交接输入焦点 |

授权后点击「重新检测权限」。仍不可用时，退出 Topit，再从 `/Applications/Topit.app` 打开。无需为日常使用操作签名钥匙串。

## 区域置顶：本仓库新增功能

### 创建一个区域

1. 将鼠标移到想截取的源窗口上，按 **Command + Shift + T**。
2. 在选区界面拖动框出需要保留的部分，松开鼠标生成浮窗。按 **Esc** 取消；单击或小于 8 点的选区不会创建浮窗。
3. 也可以打开窗口选择器，先选中窗口缩略图，再点击「区域置顶…」。通过菜单栏进入时，先点选源窗口，再框选区域。

浮窗只显示所选内容。可为不同窗口创建多个区域；实时捕获最高 30 fps，并受设置中的捕捉帧率上限约束。

### 交互与编辑

| 操作 | 效果 |
| --- | --- |
| 普通点击、拖动、滚动 | 映射到源窗口中的对应位置 |
| 点击源输入框在浮窗中的位置 | 尝试将真实键盘焦点交给原输入框，后续输入由原应用处理 |
| 按住 Shift 拖动 | 移动区域浮窗 |
| 按住 Shift 拖动边缘 | 等比缩放区域浮窗 |
| 按住 Shift 并移到浮窗上 | 显示关闭区域、冻结、复制截图按钮 |
| Shift + 右键 | 打开冻结/恢复、复制截图、打开源窗口、关闭区域和不透明度菜单 |

松开 Shift 后恢复区域交互。输入时不创建额外编辑框，不复制草稿，也不生成键盘事件副本。是否能正确聚焦、输入和使用输入法，需要由具体源应用支持。

「冻结」保留当前画面并停止该区域的捕获和输入；通过恢复按钮重新开始。「复制截图」复制当前区域画面。「关闭区域浮窗」只关闭浮窗；「打开源窗口」会主动前置原窗口。源窗口关闭后，浮窗保留最后一帧。

### 双击 Control 自动隐藏

连续轻按两次 **Control** 开启自动隐藏，再轻按两次关闭。也可从「区域截取」或菜单栏的「区域自动隐藏（双击 Control）」切换。

- 开启后，鼠标靠近区域浮窗时淡出，离开后重新显示。
- **整个模式开启期间都不能操作区域浮窗**，包括点击、输入、滚动和 Shift 编辑；浮窗重新显示不代表已恢复交互。
- 关闭此模式后恢复原透明度和交互。设置作用于所有区域浮窗，新创建的区域也沿用当前状态；重启 Topit 后默认关闭。
- Control 组合键、长按，以及两次轻按之间的点击或滚动，不会作为双击触发。

## 整窗置顶：原项目已有功能的用法

### 选择并置顶整个窗口

1. 从 Topit 主界面或菜单栏的「窗口选择器」打开窗口列表。
2. 在对应显示器页选择窗口缩略图，点击 **「立即置顶」**。
3. 也可以使用菜单栏的「置顶某个窗口」或选择器的「使用鼠标选择窗口」，再直接点击目标窗口；按 Esc 退出选择。

对其他窗口重复操作即可同时置顶多个窗口。通过原项目的整窗交互方式激活后，可以按普通窗口的方式操作、移动和缩放源窗口；此模式不采用区域浮窗的 Shift 编辑规则。

### 整窗控制菜单

将鼠标移到置顶窗口的控制角，点击 Topit 图标打开菜单。控制角的位置可在设置中调整。

| 原有菜单项 | 用法与影响 |
| --- | --- |
| 解除置顶 | 移除置顶浮层，保留原窗口 |
| 暂停置顶 / 恢复置顶 | 暂时解除置顶并停止捕获，再恢复整窗置顶；与区域模式的冻结截图不同 |
| 不透明度 | 使用滑块调整整窗透明度；半透明模式下需先暂停置顶，再缩放窗口 |
| 关闭窗口 | 关闭原应用窗口，同时移除浮层；请与「解除置顶」区分 |

菜单栏或 Dock 菜单中的「解除所有置顶」同时关闭整窗浮层和区域浮窗。

### 原有设置

从选择器齿轮、Topit 菜单或菜单栏打开「设置…」。

| 设置页 | 原项目保留的功能及用法 |
| --- | --- |
| 通用 | 开机启动、Dock 图标、菜单栏图标 |
| 窗口设置 → 置顶窗口激活方式 | 默认鼠标悬停激活；可改为左键单击，选择单击时需先激活再移动窗口 |
| 窗口设置 → 防止输入焦点改变 | 选择单击激活后可启用，避免鼠标经过置顶窗口打断当前输入；启用后需双击激活整窗 |
| 窗口设置 → 控制按钮位置 | 在四个角之间选择整窗控制菜单的位置 |
| 窗口设置 → 捕捉帧率上限 | 选择 30、60、120 Hz 或不限制；实际整窗帧率受显示器限制，区域模式最高仍为 30 fps |
| 窗口设置 → 在多个窗口间自动闪避 | 自动隐藏与当前激活窗口重叠的其他整窗浮层 |
| 窗口设置 → 为半透明窗口添加边框 | 为整窗半透明模式显示边框 |
| App 过滤器 | 切换是否显示无标题窗口；用「+」添加要从选择器隐藏的应用，用「−」移除过滤项 |

### 原有 AppleScript 命令

原项目的脚本入口继续保留。可在 macOS「脚本编辑器」中调用，例如：

```applescript
tell application "Topit"
    show selector
end tell
```

| 命令 | 用途 |
| --- | --- |
| `show selector` | 打开窗口选择器 |
| `select a window` | 进入鼠标点选整窗的模式 |
| `toggle frontmost` | 对最前面的窗口切换整窗置顶状态 |
| `toggle under mouse` | 对鼠标所指窗口切换整窗置顶状态 |
| `unpin all windows` | 解除全部置顶；本仓库中也会关闭区域浮窗 |

这些脚本命令没有新增区域框选接口，完整定义见 [Scriptable.sdef](Topit/Scriptable/Scriptable.sdef)。

## 快捷键

| 功能 | 当前默认值 / 设置方式 |
| --- | --- |
| 区域框选 | Command + Shift + T；在设置 → 快捷键设置中修改 |
| 区域自动隐藏 | 连续轻按两次 Control；当前为固定手势 |
| 区域编辑 | 按住 Shift |
| 取消正在进行的选择 | Esc |
| 原有整窗选择、打开选择器、鼠标所指/最前面窗口的置顶切换、解除全部置顶 | 在设置 → 快捷键设置中自行绑定，当前代码未提供默认组合键 |

本仓库已将原整窗快捷键 Command + Shift + T 迁移为区域框选；整窗置顶仍可通过按钮、菜单或自定义快捷键使用。

## 已知限制

- 原窗口仍必须存在。完全遮挡、最小化、切换 Space 或受保护内容可能使源应用停止刷新；这不是所有应用上都已解决的问题。
- 区域输入依赖 macOS 私有窗口焦点接口，兼容性会随系统和应用而变化。请求焦点时不主动抬升源窗口，但源应用仍可能自行前置。
- 后台指针采用 Command 点击语义；链接或特殊控件可能表现为 Command 点击。
- Codex 的实体键盘输入、中文输入法及窗口层级尚未完成安装版验收。自动测试通过不代表已经兼容所有输入框。
- 源窗口关闭或捕获中断后，最后一帧不再提供实时交互。重启或更新 Topit 会关闭当前浮窗，需要重新创建。

## 更新与开发

本仓库关闭了上游 Sparkle 自动更新。「检查更新…」显示当前功能版本的更新说明；新版本从本仓库 Releases 获取。

`.topitupdate` 是针对**确切旧版本、文件内容和签名身份**的增量包，不是通用安装包。应用前先运行 `Scripts/topit_update.py apply 更新包路径 --check`；匹配后才应用更新。正常更新先备份旧版，失败回退，不清除偏好和权限记录。首次签名身份迁移仍可能重新要求授权。

例如，v0.1.22 的增量包适用于同证书签名的 0.1.21/build31。完整安装、证书迁移和发布维护说明见 [发布文档](docs/RELEASING.md)。

开发者使用 Xcode 打开 `Topit.xcodeproj`，选择 `Topit` scheme。运行全部自动检查：

```bash
bash Scripts/test.sh
```

GitHub CI 在 Intel 和 Apple Silicon 上执行回归，并编译通用 Release。仅编译构建目录中的应用；交互验收使用正式安装到 `/Applications/Topit.app` 的版本。
